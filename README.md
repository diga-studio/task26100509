# bim_clash — BIM 构件增量碰撞检测库

纯 Python 标准库实现（兼容 3.11+），无第三方依赖。构件几何为项目局部坐标系下的
轴对齐包围盒（AABB），单位米；数据全部驻留内存。

## 接口

```python
from bim_clash import Element, Scene

scene = Scene()
scene.build([Element(1, 0, 0, 0, 1, 1, 1), ...])   # 建立场景及初始碰撞状态
result = scene.apply(upserts=[...], deletes=[...])  # 批量增/替/删，返回增量
all_clashes = scene.clashes()                       # 当前全部碰撞，每对恰好一次
```

- 碰撞判定：三轴重叠长度（`min(上界) - max(下界)`）均严格大于 0；贴面、贴边、
  贴点不算碰撞，不使用任何容差。
- `apply` 返回 `ApplyResult(added, removed, updated)`：`added` 为新出现的对，
  `removed` 为消失的对（携带旧尺寸），`updated` 为仍存在但重叠尺寸变化的对
  （携带新尺寸）。增量恰好等于整批执行前后两个场景的碰撞差异，不暴露逐个修改
  产生的临时碰撞；三个集合互不重复、互不交叉。
- `upserts` 中已有 id 表示整体替换包围盒；两组 id 互不相交，删除目标必须存在，
  违反时抛出异常。

## 复杂度

设构件数 `n`、单批修改数 `k`、真实碰撞数 `c`：

- `build`：沿 x 轴排序扫掠，`O(n log n + n·a + c)`，其中 `a` 为扫掠窗口内的
  平均活跃构件数（与几何分布有关，远小于 `n`）。
- `apply`：先以 `O(c_a)` 摘出受影响的旧碰撞（`c_a` 为触及被改构件的碰撞数），
  再对 `k` 个受影响构件沿 x 轴二分裁剪候选并逐一精确判定，代价
  `O(n log n + k·q + c_a)`，其中 `q` 为每个被改构件在 x 轴上的平均候选数。
  与整场景重算不同，代价随 `k` 而非 `n·k` 之外的全量配对增长；未受影响的
  碰撞对完全不被触碰。
- `clashes`：`O(c log c)`（按构件对排序输出）。
- 内存：`O(n + c)`。

## 运行测试

```bash
python3 -m unittest test_bim_clash -v
```

测试内容：固定随机种子生成 40 构件初始场景并连续施加 30 个混合批次（新增、
删除、替换、重复提交相同几何、仅重叠尺寸微变），每批用独立穷举实现核对三类
增量、重叠尺寸与完整当前碰撞集；另有同批交换两个不相交构件位置（不得产生
临时增量）、贴面/贴边/贴点不算碰撞、1e-9 极薄正厚度交叠算碰撞的专项用例。
